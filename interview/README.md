# Entrevistas

Entrevistas a munícipes do Porto para perceber se a fragmentação dos serviços da cidade é um problema real e validar as ideias principais da app.

| Ficheiro | Descrição |
|---|---|
| `Guiao-Entrevista-Municipes-Porto.docx` | Guião de entrevista (modelo em branco) |
| `Guiao-Entrevista-Porto-SIM01.docx` … `SIM06.docx` | As 6 entrevistas realizadas, com as respostas sintetizadas (participantes anónimos) |
| `Interview.excalidraw` | Mapa visual da entrevista / síntese das respostas |

> Os ficheiros `.excalidraw` abrem-se em [excalidraw.com](https://excalidraw.com) (File → Open) ou com a extensão Excalidraw do VS Code.
