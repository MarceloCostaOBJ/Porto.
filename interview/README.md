# Interviews

Interviews with Porto residents to check whether the fragmentation of the city's services is a real problem and to validate the app's main ideas.

| File | Description |
|---|---|
| `Interview-Guide-Porto.docx` | Interview guide (blank template) |
| `Interview-Porto-SIM01.docx` … `SIM06.docx` | The 6 interviews conducted, with summarised answers (anonymous participants) |
| `Interview.excalidraw` | Visual map of the interview / summary of the answers |

> The interview documents are written in Portuguese, since the participants are Porto residents.
>
> `.excalidraw` files can be opened at [excalidraw.com](https://excalidraw.com) (File → Open) or with the Excalidraw extension for VS Code.
